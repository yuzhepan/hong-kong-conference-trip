## 行程要点

- 伯惠酒店：香港西营盘东边街11号，西营盘站A1出口。
- 22日09:00武汉站出发，深圳北13:26发车，13:44抵香港西九龙；武汉至深圳北到站时间与车次待按车票补填。
- 22日白天2人，20:30在西九龙接另外2人，此后4人行动。目标20:00–20:10到B2公共抵港区域；若20:30是同伴列车抵达时间，仍须等通关。
- 22日下午华乐冰室按16:00收档安排：为争取到店时间，默认先打车到酒店，未出关或未安置好时电话确认、必要时跳过。另提供详细地铁路线，选择地铁通常更难赶上华乐。
- 22日接人后打车直接去光记食店，再回酒店。目标21:45入座，参考22:45关门；最后点单时间未确认，不保证能赶上。周一休息，准备现金。
- 钟江海会议中心：薄扶林沙宣道21号医学院蒙民伟楼地下，不是香港大学本部。
- 23日08:30报到、09:00开幕、18:00结束；晚宴18:00–20:00仅限受邀者。24日09:00–17:00。
- 25日官方议程09:00–16:30，但13:58从西九龙返武汉。只安排09:00–10:15首场，10:15离场，回酒店取行李，11:20离酒店，12:00到站。12:28起办理手续；所有登车节点按当日公告。
- 四人乘的士通常前排1人、后排3人，每人系安全带，包括后排中间。行李过多分两车。

四天表内餐饮交通估算：22日HK$1,020、23日HK$880、24日HK$810、25日HK$800，合计HK$3,510。包含华乐即使因晚到跳过时也先计预留；不含高铁、酒店、会议费、未确认会务午餐与表外消费。车费是全车估算，分车需要另增预算。

## 使用

- 每日行程：切换日期、添加、编辑、完成勾选；修改预算时选择每人或全组。
- 老店食单：6家餐厅、分区筛选、收藏、加入行程、电话和真实点评来源。
- 街道景点：实景照片、介绍、作者和许可、真实游客或媒体点评；可加入行程。
- 交通图解：B4下车、B2通关、L1 M出口去九龙站、东涌线至香港、站内换中环港岛线、西营盘A1到酒店；官方地图可点开放大。
- 导航：高德按完整地址搜索，确认商家后点“路线”；Google Maps提供起终点与出行方式备选，地图需联网。
- 我的备忘：清单、备注、JSON导出/导入、ICS日历提醒、来源汇总。

首次在线打开并等待缓存完成，之后可离线查看页面、照片、站图和编辑（约9MB）；外部地图、电话、来源网页仍需相应网络或通信服务。首次下载没完成时不保证所有照片离线可见。

电脑和手机不会自动同步。换设备或从本地预览换到正式网址前，导出JSON，再在目标浏览器导入。日历提醒需把ICS导入手机日历并允许通知。清理浏览器数据前先备份。

## 本地预览与更新

PowerShell 7 中进入此目录，运行 `node server.mjs`，打开 http://localhost:4173/ 。也可运行 `启动预览.ps1`。请通过HTTP访问，不要双击HTML文件。

修改后运行 `node prepare-release.mjs` 更新离线资源清单；缓存版本根据资源内容自动更新，激活新版本时会清理旧缓存。通过 `npm run check` 或直接 `node --check` 检查各JS文件。没有Python/R编译步骤。

主分支保存完整源码；`gh-pages`分支由`dist/`拆出，在GitHub Pages设置中使用该分支根目录发布：

```powershell
git add dist README.md package.json server.mjs prepare-release.mjs .gitignore
git commit -m "Update travel plan"
git subtree split --prefix dist -b gh-pages
git push origin main gh-pages
```
